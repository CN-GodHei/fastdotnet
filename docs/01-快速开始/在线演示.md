## ⚠️ 注意事项

### 数据安全

1. **定期重置**：演示环境的数据会定期重置（通常每周一次）
2. **不要存储重要数据**：请勿在演示环境中创建或上传敏感信息
3. **公开访问**：演示环境是公开的，任何人都可以访问

### 使用限制

1. **性能限制**：演示环境可能有性能限制，响应速度不如本地部署
2. **功能限制**：部分高级功能可能在演示环境中禁用
3. **并发限制**：同时在线用户数可能有限制

### 最佳实践

✅ **推荐做法**：
- 浏览各个功能模块
- 测试基本的增删改查操作
- 体验用户界面和交互
- 了解系统架构和功能范围

❌ **不推荐做法**：
- 存储个人或商业敏感数据
- 进行压力测试或性能测试
- 依赖演示环境进行生产决策
- 长时间占用系统资源

## 🚀 本地部署

如果你想获得完整的体验和更好的性能，建议本地部署：

### 快速开始

```bash
# 1. 克隆项目
git clone https://gitee.com/CN-GodHei/fastdotnet.git
cd fastdotnet

# 2. 启动后端
cd backend/Fastdotnet.WebApi
dotnet run

# 3. 启动前端（新终端）
cd Web/fastdotnet-admin
pnpm install
pnpm dev
```

## 💡 常见问题

### Q: 演示环境的账号密码是什么？

**A**: 
- 管理端：`superadmin` / `123456`
- 应用端：`admintest` / `123456`

### Q: 为什么我无法登录？

**A**: 
1. 检查网络连接
2. 确认账号密码正确（注意大小写）
3. 演示环境可能正在维护或重启
4. 尝试清除浏览器缓存

### Q: 演示环境的数据多久重置一次？

**A**: 通常每周重置一次，具体时间不固定。建议在本地部署以获得持久化的数据。

### Q: 可以在演示环境中创建新用户吗？

**A**: 可以，但请注意：
- 新创建的用户会在下次重置时被删除
- 不要使用真实个人信息
- 建议使用测试账号，如 `test001`、`demo_user` 等

### Q: 演示环境支持哪些浏览器？

**A**: 推荐使用现代浏览器：
- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+
