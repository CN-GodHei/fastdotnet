# 环境准备

在开始插件开发之前，需要安装必要的开发工具和环境。

---

## 📋 必需软件

### 1. .NET 10 SDK

**下载地址**: [https://dotnet.microsoft.com/download/dotnet/10.0](https://dotnet.microsoft.com/download/dotnet/10.0)

**验证安装**:
```bash
dotnet --version
# 应输出: 10.0.x
```

### 2. Node.js 18+

**下载地址**: [https://nodejs.org/](https://nodejs.org/)

**验证安装**:
```bash
node --version
# 应输出: v18.x.x 或更高
```

### 3. pnpm

**安装命令**:
```bash
npm install -g pnpm
```

**验证安装**:
```bash
pnpm --version
# 应输出: 8.x.x 或更高
```

### 4. Git

**下载地址**: [https://git-scm.com/](https://git-scm.com/)

**验证安装**:
```bash
git --version
```

### 5. IDE（任选其一）

- **Visual Studio 2022** (推荐 Windows 用户)
  - 下载: [https://visualstudio.microsoft.com/](https://visualstudio.microsoft.com/)
  - 工作负载: ASP.NET 和 Web 开发

- **VS Code** (跨平台，轻量级)
  - 下载: [https://code.visualstudio.com/](https://code.visualstudio.com/)
  - 推荐扩展:
    - C# Dev Kit
    - Vue Language Features (Volar)
    - ESLint
    - Prettier

- **JetBrains Rider** (跨平台，功能强大)
  - 下载: [https://www.jetbrains.com/rider/](https://www.jetbrains.com/rider/)

- **Postman**

### 版本管理

- **GitHub Desktop**
- **SourceTree**

## ✅ 环境验证

运行以下命令验证所有工具是否安装成功：

```bash
# .NET
dotnet --version

# Node.js
node --version
npm --version

# pnpm
pnpm --version

# Git
git --version
```
