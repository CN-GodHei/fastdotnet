## 🚀 快速开始

### 1. 安装依赖

```bash
cd Web/fastdotnet-admin
pnpm install
```

### 2. 启动开发服务器

```bash
pnpm dev
```

访问：http://localhost:8080

### 3. 创建插件

```bash
# 使用 CLI 工具
fd-plugin create my-plugin

# 或手动创建（参考插件开发指南）
```

## 📖 推荐阅读顺序

1. **新手入门**：
   - 阅读 [index.md](./index.md) 了解项目概况
   - 按照"开发环境"章节配置本地环境
   - 阅读"核心技术"了解技术栈

2. **深入理解**：
   - 阅读 [核心概念.md](./核心概念.md) 理解架构设计
   - 重点学习"插件化架构"和"安全机制"

3. **插件开发**：
   - 阅读 [插件开发指南.md](./插件开发指南.md)
