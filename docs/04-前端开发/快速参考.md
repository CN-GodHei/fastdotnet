# Fastdotnet 前端开发快速参考

## 🚀 快速命令

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 代码检查
pnpm lint-fix
```

## 📁 重要目录

```
src/
├── api/              # API 接口定义
├── components/       # 公共组件
├── plugins/          # 插件系统核心
├── router/           # 路由配置
├── stores/           # Pinia 状态管理
├── utils/            # 工具函数
│   ├── request.ts    # Axios 封装
│   └── signalr.ts    # SignalR 封装
└── views/            # 页面视图
```

## 🔑 核心概念

### 1. 插件系统

```typescript
// 主应用传递共享服务
props: {
  FdRequest: request,              // Axios 实例
  signalRManager: baseSignalRManager,  // SignalR
  uploadService: uploadService,        // 上传服务

```

### 2. API 调用

```typescript
import request from '@/utils/request'

// GET 请求
const data = await request({
  url: '/api/admin/FdUser/GetPage',
  method: 'get',
  params: { pageIndex: 1, pageSize: 10 }
})

// POST 请求
const result = await request({
  url: '/api/admin/FdUser/Create',
  method: 'post',
  data: userData
})
```

### 3. 状态管理

```typescript
import { useUserInfo } from '@/stores/userInfo'

const userStore = useUserInfo()

// 读取
console.log(userStore.userInfos.username)

// 修改
userStore.setUserInfos({ id: '1', username: 'admin' })
```

### 4. 路由跳转

```typescript
import { useRouter } from 'vue-router'

const router = useRouter()

// 跳转
router.push('/system/user')

// 带参数
router.push({ path: '/user/detail', query: { id: '123' } })
```

## 🔒 安全机制

### 防重放签名

自动在请求头中添加：
- `X-Timestamp`: 时间戳
- `X-Nonce`: 随机数
- `X-Signature`: HMAC-SHA256 签名

### 时间同步

```typescript
import { timeSyncService } from '@/utils/request'

// 手动同步时间
await timeSyncService.syncTime(true)
```

## 🐛 常见问题

### Q: 路由刷新后 404？

**A**: 确保 `vite.config.ts` 中设置了 `appType: 'spa'`

### Q: 插件白屏？

**A**: 检查：
1. 控制台错误
2. base 路径是否正确
3. CORS 是否配置

### Q: 如何清除缓存？

```typescript
// 清除 localStorage
localStorage.clear()

// 重置 Store
const themeStore = useThemeConfig()
themeStore.$reset()
```
