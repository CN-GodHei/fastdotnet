## 🔌 插件化架构

### 为什么需要插件化？

1. **模块化开发**：不同团队独立开发不同功能模块
2. **按需加载**：只加载用户有权限的插件
3. **技术隔离**：每个插件可以使用不同的技术栈
4. **独立部署**：插件可以独立更新和部署
5. **生态扩展**：第三方开发者可以提供插件

## 🔒 安全机制

### 防重放攻击

#### 攻击场景

```
攻击者截获合法请求 → 重复发送相同请求 → 造成数据错误或资源浪费
```

#### 防护方案

**1. 时间戳 + 随机数 (Nonce)**

```typescript
const timestamp = timeSyncService.getServerTimestampInSeconds()
const nonce = `${generateUUID()}-${Date.now()}`
```

**2. HMAC-SHA256 签名**

```typescript
// 签名字符串
const signContent = `${timestamp}|${nonce}|${method}|${path}|${body}`

// 生成签名
const signature = CryptoJS.HmacSHA256(signContent, secretKey)
  .toString(CryptoJS.enc.Base64)
```

**3. 后端验证**

```csharp
// 后端验证逻辑（C#）
public class AntiReplayMiddleware
{
    public async Task InvokeAsync(HttpContext context)
    {
        var timestamp = int.Parse(context.Request.Headers["X-Timestamp"]);
        var nonce = context.Request.Headers["X-Nonce"];
        var signature = context.Request.Headers["X-Signature"];
        
        // 1. 验证时间窗口（5分钟内有效）
        var serverTime = GetServerTime();
        if (Math.Abs(serverTime - timestamp) > 300)
        {
            throw new BusinessException("请求已过期");
        }
        
        // 2. 验证 Nonce 唯一性（防止重放）
        if (await _cache.ExistsAsync($"nonce:{nonce}"))
        {
            throw new BusinessException("重复的请求");
        }
        
        // 3. 验证签名
        var expectedSignature = GenerateSignature(timestamp, nonce, ...);
        if (signature != expectedSignature)
        {
            throw new BusinessException("签名验证失败");
        }
        
        // 4. 记录 Nonce（过期后自动删除）
        await _cache.SetAsync($"nonce:{nonce}", 1, TimeSpan.FromMinutes(5));
        
        await _next(context);
    }
}
```

### 时间同步

#### 问题

客户端和服务器时间不一致会导致签名验证失败。

#### 解决方案

**精确同步（考虑 RTT）：**

```typescript
class TimeSyncService {
  private offset: number = 0
  
  async syncTime(force: boolean = false): Promise<void> {
    const localSendTime = Date.now()
    
    // 发送请求
    const response = await fetch('/api/GetServiceDateTime')
    const serverTime = parseInt(response.headers.get('X-Server-Timestamp'))
    
    const localRecvTime = Date.now()
    const rtt = localRecvTime - localSendTime
    
    // 核心算法：offset = ServerTime - (SendTime + RTT/2)
    this.offset = serverTime - (localSendTime + rtt / 2)
  }
  
  getServerTimestampInSeconds(): number {
    return Math.floor((Date.now() + this.offset) / 1000)
  }
}
```

**粗略校准（从响应头）：**

```typescript
tryCalibrateFromResponse(serverTimestamp: number): void {
  const now = Date.now()
  
  // 只有在长时间未同步时才校准（避免抖动）
  if (now - this.lastSyncTime < 15 * 60 * 1000) {
    return
  }
  
  this.offset = serverTimestamp - now
  this.lastSyncTime = now
}
```

## 🗺️ 路由系统

### 路由模式对比

| 模式 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **后端控制** | 动态权限、灵活配置 | 需要后端支持 | 企业级应用 |
| **前端控制** | 简单直接、快速开发 | 权限控制较弱 | 小型项目 |

### 后端控制路由流程

```
1. 用户登录
   ↓
2. 获取用户信息和菜单树
   ↓
3. 解析菜单为路由配置
   ↓
4. 动态添加路由 (router.addRoute)
   ↓
5. 渲染侧边栏菜单
   ↓
6. 用户访问页面
```

### 路由解析

```typescript
// src/router/backEnd.ts

/**
 * 解析菜单为路由
 */
function parseMenusToRoutes(menus: MenuItem[]): RouteRecordRaw[] {
  const routes: RouteRecordRaw[] = []
  
  for (const menu of menus) {
    const route: RouteRecordRaw = {
      path: menu.Path,
      name: menu.Name,
      component: loadComponent(menu.Component),
      meta: {
        title: menu.Title,
        icon: menu.Icon,
        isKeepAlive: menu.IsKeepAlive,
        isFdMicroApp: menu.IsFdMicroApp,
        pluginId: menu.PluginId
      }
    }
    
    // 递归处理子菜单
    if (menu.Children?.length > 0) {
      route.children = parseMenusToRoutes(menu.Children)
    }
    
    routes.push(route)
  }
  
  return routes
}

/**
 * 动态加载组件
 */
function loadComponent(component: string) {
  // 微应用
  if (component === 'MicroApp') {
    return () => import('@/layout/routerView/microApp.vue')
  }
  
  // 普通组件
  return () => import(`@/views/${component}.vue`)
}
```

```typescript
router.beforeEach(async (to, from, next) => {
```

## ⚡ 实时通信

### SignalR 集成

Fastdotnet 集成了 SignalR，支持实时通信。

**封装类：**

```typescript
// src/utils/signalr.ts
import * as signalR from '@microsoft/signalr'

export class SignalRManager {
  private connection: signalR.HubConnection | null = null
  private reconnectAttempts = 0
  private maxReconnectAttempts = 5
  
  constructor(private hubUrl: string) {}
  
  /**
   * 启动连接
   */
  async start(): Promise<void> {
    this.connection = new signalR.HubConnectionBuilder()
      .withUrl(this.hubUrl, {
        accessTokenFactory: () => Session.get('token') || ''
      })
      .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
      .build()
    
    // 注册事件处理器
    this.registerHandlers()
    
    // 启动连接
    await this.connection.start()
    console.log('[SignalR] Connected')
    
    this.reconnectAttempts = 0
  }
  
  /**
   * 注册事件处理器
   */
  private registerHandlers() {
    if (!this.connection) return
    
    // 通用消息
    this.connection.on('ReceiveMessage', (message: any) => {
      console.log('[SignalR] ReceiveMessage', message)
      // 触发事件
      emitter.emit('signalr:message', message)
    })
    
    // 通知
    this.connection.on('ReceiveNotification', (notification: any) => {
      console.log('[SignalR] ReceiveNotification', notification)
      emitter.emit('signalr:notification', notification)
    })
    
    // 在线用户更新
    this.connection.on('OnlineUsersUpdated', (users: any[]) => {
      console.log('[SignalR] OnlineUsersUpdated', users)
      emitter.emit('signalr:online-users', users)
    })
  }
  
  /**
   * 发送消息
   */
  async send(method: string, ...args: any[]): Promise<void> {
    if (!this.connection) {
      throw new Error('SignalR not connected')
    }
    
    await this.connection.invoke(method, ...args)
  }
  
  /**
   * 断开连接
   */
  async stop(): Promise<void> {
    if (this.connection) {
      await this.connection.stop()
      this.connection = null
    }
  }
}

// 创建全局实例
export const baseSignalRManager = new SignalRManager(
  `${import.meta.env.VITE_API_URL}/api/universalhub`
)
```

```vue
import { onMounted, onUnmounted } from 'vue'
import { baseSignalRManager } from '@/utils/signalr'
import { emitter } from '@/utils/mitt'

onMounted(async () => {
  // 启动 SignalR 连接
  await baseSignalRManager.start()
  
  // 监听消息
  emitter.on('signalr:message', handleMessage)
  emitter.on('signalr:notification', handleNotification)
})

onUnmounted(() => {
  // 移除监听
  emitter.off('signalr:message', handleMessage)
  emitter.off('signalr:notification', handleNotification)
  
  // 断开连接
  baseSignalRManager.stop()
})

const handleMessage = (message: any) => {
  console.log('收到消息', message)
}

const handleNotification = (notification: any) => {
  ElNotification({
    title: notification.title,
    message: notification.content,
    type: 'info'
  })
}
</script>
```
