## 🏗️ 插件架构

Fastdotnet 采用 **Qiankun** 微前端框架实现插件化架构。

### 架构图

```
┌─────────────────────────────────────────────┐
│           主应用 (fastdotnet-admin)          │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │   插件容器 (#subapp-viewport)         │  │
│  │                                       │  │
│  │  ┌─────────────┐ ┌──────────────┐    │  │
│  │  │  Plugin A   │ │  Plugin B    │    │  │
│  │  │  (独立运行)  │ │  (独立运行)   │    │  │
│  │  └─────────────┘ └──────────────┘    │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

### 核心特性

- ✅ **技术栈无关**：插件可以使用 Vue、React、Angular 等任意框架
- ✅ **独立部署**：每个插件可以独立构建和部署
- ✅ **样式隔离**：自动隔离插件样式，避免冲突
- ✅ **JS 沙箱**：独立的 JavaScript 执行环境
- ✅ **按需加载**：根据权限动态加载插件

## 🚀 快速开始

### 使用 CLI 创建插件

```bash
# 安装 CLI 工具
npm install -g fastdotnet-plugin-cli

# 创建新插件
fd-plugin create my-plugin

# 选择模板
# ✓ Vue 3 + TypeScript
# ✓ React + TypeScript
# ✓ Vanilla JS

# 进入项目目录
cd my-plugin

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

### 手动创建插件

**1. 初始化项目**

```bash
# 创建项目目录
mkdir my-plugin
cd my-plugin

# 初始化 package.json
npm init -y

# 安装依赖
pnpm add vue vue-router pinia
pnpm add -D vite @vitejs/plugin-vue typescript
```

**2. 创建 Vite 配置**

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  base: '/plugins/my-plugin/',  // 重要：设置基础路径
  server: {
    port: 8090,
    cors: true,
    headers: {
      'Access-Control-Allow-Origin': '*'  // 允许跨域
    }
  },
  build: {
    outDir: 'dist',
    rollupOptions: {
      output: {
        entryFileNames: 'assets/[name].js',
        chunkFileNames: 'assets/[name].js',
        assetFileNames: 'assets/[name].[ext]'
      }
    }
  }
})
```

**3. 创建入口文件**

```typescript
// src/main.ts
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

let instance: any = null

/**
 * 渲染函数
 */
function render(props: any = {}) {
  const { container } = props
  
  instance = createApp(App)
  instance.use(router)
  instance.mount(container ? container.querySelector('#app') : '#app')
}

/**
 * bootstrap: 只会在微应用初始化的时候调用一次
 */
export async function bootstrap() {
  console.log('[MyPlugin] bootstrap')
}

/**
 * mount: 微应用被挂载时调用
 */
export async function mount(props: any) {
  console.log('[MyPlugin] mount', props)
  
  // 接收主应用传递的共享依赖
  const { FdRequest, signalRManager, uploadService } = props
  
  // 将共享服务注入到全局
  if (FdRequest) {
    app.config.globalProperties.$request = FdRequest
  }
  
  render(props)
}

/**
 * unmount: 微应用被卸载时调用
 */
export async function unmount() {
  console.log('[MyPlugin] unmount')
  
  instance.unmount()
  instance._container.innerHTML = ''
  instance = null
}

/**
 * update: 微应用被更新时调用（可选）
 */
export async function update(props: any) {
  console.log('[MyPlugin] update', props)
}

// 独立运行时直接挂载
if (!window.__POWERED_BY_QIANKUN__) {
  render()
}
```

## 🔄 生命周期

Qiankun 微应用有四个生命周期钩子：

### 1. bootstrap

只在微应用初始化时调用一次。

```typescript
export async function bootstrap() {
  console.log('[MyPlugin] bootstrap - 初始化')
  
  // 可以在这里进行一次性初始化
  // 例如：加载全局配置、初始化 SDK 等
}
```

### 2. mount

微应用被挂载时调用，每次激活都会执行。

```typescript
export async function mount(props: any) {
  console.log('[MyPlugin] mount - 挂载', props)
  
  // 1. 接收主应用传递的参数
  const { 
    base,              // 基础路径
    FdRequest,         // Axios 实例
    signalRManager,    // SignalR 管理器
    uploadService,     // 上传服务
    menuInfo           // 菜单信息
  } = props
  
  // 2. 设置路由基础路径
  router.base = base
  
  // 3. 注入共享服务
  if (FdRequest) {
    app.config.globalProperties.$request = FdRequest
  }
  
  // 4. 渲染应用
  render(props)
}
```

### 3. unmount

微应用被卸载时调用。

```typescript
export async function unmount() {
  console.log('[MyPlugin] unmount - 卸载')
  
  // 1. 卸载 Vue 实例
  instance.unmount()
  
  // 2. 清空容器
  instance._container.innerHTML = ''
  
  // 3. 释放资源
  instance = null
  
  // 4. 清理定时器、事件监听器等
  cleanup()
}
```

### 4. update（可选）

微应用被更新时调用。

```typescript
export async function update(props: any) {
  console.log('[MyPlugin] update - 更新', props)
  
  // 处理参数更新
  // 例如：主题切换、语言切换等
}
```

### 生命周期流程图

```
首次加载：
  bootstrap → mount → 显示页面

切换路由（离开插件）：
  unmount

再次访问插件：
  mount → 显示页面

卸载插件：
  unmount
```

## 🔗 共享依赖

主应用通过 `props` 向插件传递共享服务。

### 可用的共享服务

| 服务 | 类型 | 说明 |
|------|------|------|
| `FdRequest` | AxiosInstance | HTTP 客户端 |
| `FdQueryBuilder` | Object | 查询构建器 |
| `signalRManager` | SignalRManager | SignalR 管理器 |
| `uploadService` | UploadService | 上传服务 |
| `base` | string | 基础路径 |
| `menuInfo` | Object | 菜单信息 |

### 使用示例

**1. 使用共享的 Axios**

```typescript
// src/api/user.ts
import { getCurrentInstance } from 'vue'

export function getUsers() {
  const instance = getCurrentInstance()
  const request = instance?.appContext.config.globalProperties.$request
  
  return request({
    url: '/api/admin/FdUser/GetPage',
    method: 'get',
    params: { pageIndex: 1, pageSize: 10 }
  })
}
```

**2. 使用查询构建器**

```typescript
const { buildMixedQuery } = props.FdQueryBuilder

const query = buildMixedQuery({
  conditions: [
    { propertyName: 'Username', operator: 'Contains', value: 'admin' }
  ],
  orderBy: 'CreatedAt',
  orderType: 'Desc'
})

const result = await request.post('/api/admin/FdUser/Search', query)
```

**3. 使用 SignalR**

```typescript
const signalR = props.signalRManager

// 发送消息
await signalR.send('SendMessage', {
  from: 'MyPlugin',
  content: 'Hello'
})

// 监听消息
signalR.connection.on('ReceiveMessage', (message) => {
  console.log('收到消息', message)
})
```

**4. 使用上传服务**

```typescript
const upload = props.uploadService

// 上传文件
const result = await upload.uploadFile(file, {
  folder: 'my-plugin',
  maxSize: 10 * 1024 * 1024  // 10MB
})

console.log('上传成功', result.url)
```

## 🎨 样式隔离

Qiankun 提供了多种样式隔离方案。

### 1. 严格样式隔离（Shadow DOM）

```typescript
// vite.config.ts
export default defineConfig({
  qiankun: {
    useStrictStyleIsolation: true  // 启用 Shadow DOM
  }
})
```

**优点：** 完全隔离，不会泄露样式  
**缺点：** 某些全局样式（如 Element Plus）可能失效

### 2. 实验性样式隔离

```typescript
// vite.config.ts
export default defineConfig({
  qiankun: {
    useExperimentalStyleIsolation: true  // 启用实验性隔离
  }
})
```

**原理：** 自动为选择器添加前缀

```css
/* 编写时 */
.button { color: red; }

/* 运行时自动转换为 */
div[data-qiankun="my-plugin"] .button { color: red; }
```

### 3. 手动隔离（推荐）

使用 CSS Modules 或 Scoped CSS：

```vue
<style scoped>
.button {
  color: red;
}
</style>
```

**最佳实践：**

```scss
// 使用命名空间
.my-plugin {
  .button {
    color: red;
  }
  
  .card {
    padding: 20px;
  }
}
```

## 📡 通信机制

### 主应用 → 插件

通过 `props` 传递：

```typescript
// 主应用配置
props: {
  theme: 'dark',
  language: 'zh-CN',
  onNotification: (msg: string) => console.log(msg)
}

// 插件接收
export async function mount(props: any) {
  const { theme, language, onNotification } = props
  
  console.log('主题', theme)
  console.log('语言', language)
  
  // 调用回调
  onNotification('Hello from plugin')
}
```

### 插件 → 主应用

**方式 1: 通过 window 对象**

```typescript
// 插件发送
window.dispatchEvent(new CustomEvent('plugin-event', {
  detail: { type: 'notification', message: 'Hello' }
}))

// 主应用监听
window.addEventListener('plugin-event', (event: any) => {
  console.log('收到插件消息', event.detail)
})
```

**方式 2: 通过 Props 回调**

```typescript
// 主应用配置
props: {
  onUpdateBadge: (count: number) => {
    // 更新角标
  }
}

// 插件调用
props.onUpdateBadge(5)
```

### 插件 ↔ 插件

通过主应用中转：

```typescript
// 插件 A 发送
window.parent.postMessage({
  type: 'cross-plugin',
  from: 'PluginA',
  to: 'PluginB',
  data: { message: 'Hello' }
}, '*')

// 主应用转发
window.addEventListener('message', (event) => {
  if (event.data.type === 'cross-plugin') {
    // 转发给目标插件
    const targetApp = qiankunApps.find(app => app.name === event.data.to)
    targetApp.instance?.emit('cross-plugin-message', event.data.data)
  }
})

// 插件 B 接收
emitter.on('cross-plugin-message', (data) => {
  console.log('收到消息', data)
})
```

```typescript
✅ 推荐：

export async function unmount() {

if (pluginId === 'MyPlugin') {

}
```

### Q: 如何优化插件加载速度？

**A**: 
1. 使用路由懒加载
2. 压缩资源（Gzip/Brotli）
3. 使用 CDN 加载第三方库
4. 代码分割（Code Splitting）
