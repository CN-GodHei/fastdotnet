## 为什么选择 Fastdotnet？

Fastdotnet 是一个现代化的 .NET 快速开发框架，旨在帮助开发团队快速构建企业级应用。

### 💡 核心价值

> **像搭积木一样构建企业应用** - 从插件商城选择需要的功能插件，快速组装成完整系统

#### 🏪 插件商城生态
- **官方插件库**：支付、工作流、社交登录、对象存储等常用功能开箱即用
- **第三方开发者**：社区贡献的专业插件，覆盖各行业业务场景
- **快速项目交付**：外包项目通过插件组合，从"月"级别缩短到"周"级别交付
- **💰 开发者价值复用**：一次开发，多次销售 - 将通用功能封装为插件上架商城，实现从"项目制"到"产品化"的转变

### ✨ 核心特性

#### 📦 框架内置功能（开箱即用）
- **认证授权**：OIDC/SSO、JWT、RBAC权限管理、多租户隔离
- **用户管理**：管理员管理、应用用户、角色权限、密码重置
- **系统管理**：菜单、角色、字典、系统配置、通知公告、工作台
- **数据存储**：SqlSugar ORM、多数据库支持、混合缓存系统
- **前端能力**：Vue 3、Element Plus、qiankun微前端、动态路由
- **插件系统**：AssemblyLoadContext隔离、热插拔、独立依赖管理
- **安全防护**：敏感数据脱敏、防重放攻击、加密传输、操作日志
- **开发工具**：Swagger、代码生成器、CLI工具、热重载

#### 🏪 插件商城扩展（按需选择）
- **支付系统**：支付宝、微信支付、银联支付
- **工作流引擎**：Elsa Workflow、可视化流程设计
- **社交登录**：微信、QQ、钉钉等第三方登录
- **对象存储**：阿里云OSS、腾讯云COS、MinIO、AWS S3
- **消息通知**：邮件、短信、企业微信、钉钉机器人
- **富文本编辑**：TinyMCE、Quill、WangEditor等
- **报表系统**：数据报表、图表分析、打印模板
- **行业方案**：CRM、ERP、OA、电商、教育等

> 💡 **提示**：框架已内置完整的企业级应用基础能力，您可以直接基于这些功能快速开发业务逻辑。对于额外的行业特定功能，再通过插件商城扩展。

### 🎯 适用场景

- **企业管理系统**：ERP、CRM、OA 等
- **SaaS 平台开发**：多租户隔离、灵活配置
- **快速原型开发**：插件商城现成功能，快速组装
- **外包项目交付**：缩短交付周期 70%+，降低开发成本

- **微服务架构基础框架**：轻量级模块化替代方案

## 💻 技术栈

### 后端技术

- **.NET 10** - 微软最新版本的 .NET 运行时，高性能、跨平台、云原生
- **SqlSugar ORM** - 轻量级、高性能的 .NET ORM 框架，支持多数据库适配
- **OpenIddict / OIDC** - 开放身份连接协议，支持 OAuth2.0 和单点登录（SSO）
- **JWT (JSON Web Token)** - 安全的身份认证和授权机制
- **Autofac** - 强大的依赖注入（DI）容器
- **Swagger / OpenAPI** - API 文档自动生成和在线测试
- **SignalR** - 实时双向通信框架
- **Serilog** - 结构化日志记录框架

### 前端技术

- **Vue 3** - 渐进式 JavaScript 框架，组合式 API
- **TypeScript** - 类型安全的 JavaScript 超集，提升代码质量
- **Element Plus** - 基于 Vue 3 的企业级 UI 组件库
- **Vite** - 下一代前端构建工具，极速开发体验
- **Pinia** - Vue 3 官方推荐的状态管理库
- **Vue Router 4** - Vue.js 官方路由管理器
- **Axios** - 基于 Promise 的 HTTP 客户端
- **qiankun** - 蚂蚁金服开源的微前端框架，支持插件独立部署

### 数据库支持

- ✅ **SQL Server** 2019+
- ✅ **PostgreSQL** 14+
- ✅ **MySQL** 8.0+
- ✅ **SQLite** 3.x（开发测试推荐）
- ✅ **达梦数据库** DM8（国产化支持）
