## 为什么选择 Fastdotnet？

Fastdotnet 是一个现代化的 .NET 快速开发框架，旨在帮助开发团队快速构建企业级应用。

### 🌐 官方网站

- **官网**：[https://fastdotnet.top](https://fastdotnet.top)
  - 框架介绍、特性展示、成功案例
  
- **插件商城**：[https://fastdotnet.top/marketplace](https://fastdotnet.top/marketplace)
  - 海量插件供选购，快速扩展系统功能
  - 支付、工作流、报表、OSS等常用插件应有尽有

### 🎮 在线体验

无需安装，立即体验：

- **管理端演示**：http://admin.demo.fastdotnet.top/
  - 账号：`superadmin`
  - 密码：`123456`

- **应用端演示**：http://app.demo.fastdotnet.top/
  - 账号：`admintest`
  - 密码：`123456`

> 💡 提示：演示环境数据会定期重置，请勿存储重要数据。

### ✨ 核心特性

- **开箱即用**：内置用户管理、角色权限、菜单管理等常用功能
- **插件化架构**：通过插件系统实现功能模块化，便于维护和扩展
- **微前端支持**：前端采用微前端架构，插件可以独立开发和部署
- **多租户**：原生支持多租户架构，满足 SaaS 应用需求
- **高性能**：基于 .NET 10，性能优异，响应迅速
- **易扩展**：清晰的代码结构和完善的设计模式，易于二次开发

### 🎯 适用场景

- 企业管理系统（ERP、CRM、OA 等）
- SaaS 平台开发
- 快速原型开发
- 微服务架构基础框架

## 💻 技术栈

### 后端技术

- **.NET 10** - 微软最新版本的 .NET 运行时，高性能、跨平台、云原生
- **SqlSugar ORM** - 轻量级、高性能的 .NET ORM 框架，支持多数据库适配
- **OpenIddict / OIDC** - 开放身份连接协议，支持 OAuth2.0 和单点登录（SSO）
- **JWT (JSON Web Token)** - 安全的身份认证和授权机制
- **Autofac** - 强大的依赖注入（DI）容器
- **Swagger / OpenAPI** - API 文档自动生成和在线测试
- **SignalR** - 实时双向通信框架
- **Serilog** - 结构化日志记录框架

### 前端技术

- **Vue 3** - 渐进式 JavaScript 框架，组合式 API
- **TypeScript** - 类型安全的 JavaScript 超集，提升代码质量
- **Element Plus** - 基于 Vue 3 的企业级 UI 组件库
- **Vite** - 下一代前端构建工具，极速开发体验
- **Pinia** - Vue 3 官方推荐的状态管理库
- **Vue Router 4** - Vue.js 官方路由管理器
- **Axios** - 基于 Promise 的 HTTP 客户端
- **qiankun** - 蚂蚁金服开源的微前端框架，支持插件独立部署

### 数据库支持

- ✅ **SQL Server** 2019+
- ✅ **PostgreSQL** 14+
- ✅ **MySQL** 8.0+
- ✅ **SQLite** 3.x（开发测试推荐）
- ✅ **达梦数据库** DM8（国产化支持）
