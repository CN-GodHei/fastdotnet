# AI 智能体插件 - 快速参考指南

## 📌 核心概念速查

### Semantic Kernel 核心组件

```
┌─────────────────────────────────────┐
│         Kernel（内核）               │
│  ┌──────────┐  ┌──────────┐        │
│  │ Services │  │ Plugins  │        │
│  │ (AI连接)  │  │ (工具)   │        │
│  └──────────┘  └──────────┘        │
└─────────────────────────────────────┘
```

| 组件 | 说明 | 示例 |
|------|------|------|
| **Kernel** | 核心容器，管理所有 AI 组件 | `Kernel.CreateBuilder().Build()` |
| **Service** | AI 模型连接器 | OpenAI、Azure OpenAI、Hugging Face |
| **Plugin** | 扩展功能的工具函数 | WebSearch、Calculator、Email |
| **Agent** | 具有特定目标的 AI 实体 | ChatCompletionAgent |
| **Memory** | 向量存储和语义记忆 | Azure AI Search、Chroma |

## 🔧 常用代码片段

### 1. 创建 Kernel 实例

```csharp
using Microsoft.SemanticKernel;

// 方式1：OpenAI
var kernel = Kernel.CreateBuilder()
    .AddOpenAIChatCompletion(
        modelId: "gpt-4o-mini",
        apiKey: Environment.GetEnvironmentVariable("OPENAI_API_KEY")
    )
    .Build();

// 方式2：Azure OpenAI
var kernel = Kernel.CreateBuilder()
    .AddAzureOpenAIChatCompletion(
        deploymentName: "gpt-4o-mini",
        endpoint: Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT"),
        apiKey: Environment.GetEnvironmentVariable("AZURE_OPENAI_API_KEY")
    )
    .Build();
```

### 2. 执行提示词

```csharp
// 同步执行
var result = await kernel.InvokePromptAsync("写一首关于 AI 的诗");
Console.WriteLine(result);

// 流式执行
await foreach (var update in kernel.InvokePromptStreamingAsync("写一首关于 AI 的诗"))
{
    Console.Write(update);
}
```

### 3. 创建和使用插件

```csharp
using System.ComponentModel;
using Microsoft.SemanticKernel;

public class CalculatorPlugin
{
    [KernelFunction, Description("加法运算")]
    public double Add(
        [Description("第一个数")] double a,
        [Description("第二个数")] double b)
    {
        return a + b;
    }
    
    [KernelFunction, Description("乘法运算")]
    public double Multiply(
        [Description("第一个数")] double a,
        [Description("第二个数")] double b)
    {
        return a * b;
    }
}

// 注册插件
kernel.Plugins.AddFromType<CalculatorPlugin>("Calculator");

// 在提示词中使用
var prompt = @"
计算以下表达式：
1. 5 + 3 = {{Calculator.Add 5 3}}
2. 4 * 7 = {{Calculator.Multiply 4 7}}
";

var result = await kernel.InvokePromptAsync(prompt);
```

### 4. 创建 Agent

```csharp
using Microsoft.SemanticKernel.Agents;

var agent = new ChatCompletionAgent
{
    Name = "助手",
    Instructions = "你是一个友好的助手，擅长回答问题。",
    Kernel = kernel
};

// 执行
await foreach (var response in agent.InvokeAsync("你好！"))
{
    Console.WriteLine(response.Message);
}
```

### 5. 多代理协作

```csharp
// 创建多个专业代理
var billingAgent = new ChatCompletionAgent
{
    Name = "BillingAgent",
    Instructions = "你处理账单相关问题。",
    Kernel = kernel
};

var refundAgent = new ChatCompletionAgent
{
    Name = "RefundAgent",
    Instructions = "你处理退款相关问题。",
    Kernel = kernel
};

// 创建协调代理
var triageAgent = new ChatCompletionAgent
{
    Name = "TriageAgent",
    Instructions = "评估用户问题并转发给合适的代理。",
    Kernel = kernel,
    Plugins = { billingAgent, refundAgent }
};

// 执行
await foreach (var response in triageAgent.InvokeAsync("我要退款"))
{
    Console.WriteLine(response.Message);
}
```

### 6. 向量记忆

```csharp
using Microsoft.SemanticKernel.Memory;

// 创建内存存储
var memory = new MemoryBuilder()
    .WithOpenAITextEmbeddingGeneration("text-embedding-ada-002", apiKey)
    .WithMemoryStore(new VolatileMemoryStore()) // 内存存储
    .Build();

// 添加文档
await memory.SaveInformationAsync(
    collection: "docs",
    id: "doc1",
    text: "Semantic Kernel 是微软的 AI 框架"
);

// 搜索
var results = memory.SearchAsync("docs", "AI 框架", limit: 3);
await foreach (var result in results)
{
    Console.WriteLine($"Score: {result.Relevance.Score}");
    Console.WriteLine($"Text: {result.Metadata.Text}");
}
```

## 🛠️ 常见问题排查

### 问题1：API 调用失败

**症状**：`401 Unauthorized` 或 `403 Forbidden`

**解决方案**：
1. 检查 API Key 是否正确设置
2. 确认环境变量已加载
3. 验证 API Key 是否有足够配额
4. 检查网络连接和防火墙设置

### 问题2：响应时间过长

**症状**：API 响应超过 5 秒

**解决方案**：
1. 减少 `MaxTokens` 参数
2. 使用更快的模型（如 `gpt-4o-mini` 而非 `gpt-4`）
3. 实现缓存机制
4. 优化提示词长度

### 问题3：Token 费用超支

**症状**：月度账单超出预期

**解决方案**：
1. 设置 Token 配额限制
2. 实现缓存减少重复调用
3. 使用更便宜的模型
4. 优化提示词，减少不必要的上下文

### 问题4：插件无法加载

**症状**：`Plugin not found` 错误

**解决方案**：
1. 检查插件类是否标记 `[KernelFunction]`
2. 确认程序集已正确引用
3. 验证插件注册代码
4. 查看日志中的详细错误信息

### 问题5：向量搜索不准确

**症状**：搜索结果相关性低

**解决方案**：
1. 使用更好的嵌入模型（如 `text-embedding-3-large`）
2. 调整相似度阈值（默认 0.7）
3. 增加 TopK 参数
4. 优化文档分块策略

### 错误处理

```csharp
try
{
    var result = await kernel.InvokePromptAsync(prompt);
}
catch (HttpOperationException ex) when (ex.StatusCode == HttpStatusCode.TooManyRequests)
{
    // 速率限制，等待后重试
    await Task.Delay(TimeSpan.FromSeconds(5));
    result = await kernel.InvokePromptAsync(prompt);
}
catch (Exception ex)
{
    // 记录日志
    _logger.LogError(ex, "AI 调用失败");
    throw;
}
```
