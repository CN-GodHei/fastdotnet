## 项目背景与目标

### 背景
Microsoft Semantic Kernel（现已升级为 Microsoft Agent Framework）是一个企业级的 AI 代理编排框架，支持：
- 多模型连接（OpenAI、Azure OpenAI、Hugging Face 等）
- 插件化扩展机制
- 多代理协作系统
- 向量数据库集成
- 记忆和上下文管理

Fastdotnet 是一个基于 .NET 的企业级快速开发框架，具有完善的插件系统、权限管理、工作流引擎等企业级特性。

### 集成目标
1. **为企业应用注入 AI 能力**：让 Fastdotnet 用户能够轻松构建智能客服、自动化流程、智能助手等 AI 驱动的应用
2. **保持框架一致性**：遵循 Fastdotnet 的插件化架构，确保 AI 功能可插拔、可扩展
3. **降低使用门槛**：提供开箱即用的 AI 服务和可视化管理界面
4. **企业级可靠性**：支持多租户、权限控制、审计日志等企业级需求

### 核心价值
- ✅ **快速集成**：通过插件方式一键启用 AI 能力
- ✅ **灵活配置**：支持多种 AI 提供商，可动态切换
- ✅ **安全可靠**：集成 Fastdotnet 的权限体系和审计机制
- ✅ **易于扩展**：开发者可自定义 AI 插件和业务逻辑

## 技术选型分析

### 核心框架选择

| 组件 | 选型 | 版本 | 说明 |
|------|------|------|------|
| AI 编排框架 | Microsoft Semantic Kernel | 1.63.0+ | 微软官方维护，企业级支持 |
| AI 连接器 | SemanticKernel.Connectors.OpenAI | 1.63.0+ | 支持 OpenAI/Azure OpenAI |
| 插件核心 | SemanticKernel.Plugins.Core | 1.63.0-alpha | 内置常用插件（Web搜索、时间等） |
| 记忆系统 | SemanticKernel.Plugins.Memory | 1.63.0-alpha | 向量存储和语义记忆 |
| 向量数据库 | Azure AI Search / Chroma / Qdrant | 可选 | 根据部署环境选择 |

### 为什么选择 Semantic Kernel？

#### 优势
1. **微软背书**：由 Microsoft Copilot 团队开发，长期维护和更新保障
2. **多语言支持**：同时支持 .NET、Python、Java，便于跨团队协作
3. **插件生态**：丰富的内置插件和第三方插件市场
4. **企业级特性**：支持安全过滤、内容审核、监控追踪
5. **与 Fastdotnet 契合**：同为 .NET 生态，无缝集成依赖注入、中间件等

#### 对比其他方案

| 方案 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| **Semantic Kernel** | 企业级、微软支持、插件丰富 | 学习曲线较陡 | 企业应用、复杂工作流 |
| LangChain.NET | 社区活跃、示例多 | 非官方维护、稳定性待验证 | 快速原型开发 |
| AutoGen | 多代理协作强 | 资源消耗大、配置复杂 | 研究实验、多代理系统 |
| 直接调用 API | 简单直接 | 缺少编排能力、需自行实现重试/缓存 | 简单问答场景 |

**结论**：对于 Fastdotnet 这样的企业级框架，Semantic Kernel 是最佳选择。

### 分层设计

#### 1️⃣ 插件入口层 (Plugin Layer)
- **FastdotnetPluginAIAgentPlugin.cs**：插件生命周期管理
- 负责初始化 Semantic Kernel、注册服务、配置中间件

#### 2️⃣ 服务层 (Service Layer)
- **IAIAgentService**：AI 代理核心服务接口
- **IChatService**：对话管理服务接口
- **IPluginManagementService**：AI 插件管理服务接口
- **IMemoryService**：记忆和上下文管理服务接口

#### 3️⃣ 业务逻辑层 (Business Logic Layer)
- **AIAgentService**：实现代理创建、执行、监控
- **ChatService**：实现会话管理、历史记录、流式响应
- **PluginManagementService**：管理 AI 插件的注册、启用、配置
- **MemoryService**：管理向量存储、语义搜索、上下文窗口

#### 4️⃣ 数据访问层 (Data Access Layer)
- **AIConversation**：对话历史实体
- **AIMessage**：消息记录实体
- **AIPluginConfig**：AI 插件配置实体
- **VectorDocument**：向量文档实体（可选）

#### 5️⃣ API 层 (Controller Layer)
- **AIAgentController**：代理管理 API
- **ChatController**：对话交互 API
- **AIPluginController**：插件管理 API
- **MemoryController**：记忆管理 API

#### 6️⃣ 前端层 (Frontend Layer)
- **AI 工作台**：可视化代理配置和测试
- **对话界面**：类 ChatGPT 的聊天界面
- **插件市场**：浏览和安装 AI 插件
- **监控面板**：API 调用统计、性能监控

### 依赖注入设计

```csharp
// 在 ConfigureServices 中注册
builder.Register(c =>
{
    // 创建 Kernel 实例
    var kernelBuilder = Kernel.CreateBuilder();
    
    // 添加 AI 连接器（从配置读取）
    var config = c.Resolve<IOptions<AIAgentOptions>>().Value;
    if (config.DefaultProvider == "OpenAI")
    {
        kernelBuilder.AddOpenAIChatCompletion(
            config.OpenAI.ModelId,
            config.OpenAI.ApiKey
        );
    }
    else if (config.DefaultProvider == "AzureOpenAI")
    {
        kernelBuilder.AddAzureOpenAIChatCompletion(
            config.AzureOpenAI.DeploymentName,
            config.AzureOpenAI.Endpoint,
            config.AzureOpenAI.ApiKey
        );
    }
    
    return kernelBuilder.Build();
})
.As<Kernel>()
.SingleInstance();

// 注册服务
builder.RegisterType<AIAgentService>()
    .As<IAIAgentService>()
    .InstancePerLifetimeScope();

builder.RegisterType<ChatService>()
    .As<IChatService>()
    .InstancePerLifetimeScope();
```

## 数据库设计

### 核心表结构

#### 1. AI_Conversations（对话会话表）
```sql
CREATE TABLE AI_Conversations (
    Id BIGINT PRIMARY KEY,
    UserId BIGINT NOT NULL,              -- 用户ID
    AgentId VARCHAR(100) NOT NULL,       -- 代理ID
    Title NVARCHAR(200),                 -- 会话标题
    Status INT DEFAULT 1,                -- 状态：1-活跃 0-已归档
    CreatedTime DATETIME2 NOT NULL,
    UpdatedTime DATETIME2,
    LastMessageTime DATETIME2,
    MessageCount INT DEFAULT 0,          -- 消息数量
    TotalTokens INT DEFAULT 0,           -- 总Token数
    
    INDEX IX_AI_Conversations_UserId (UserId),
    INDEX IX_AI_Conversations_AgentId (AgentId)
);
```

#### 2. AI_Messages（消息记录表）
```sql
CREATE TABLE AI_Messages (
    Id BIGINT PRIMARY KEY,
    ConversationId BIGINT NOT NULL,      -- 会话ID
    Role VARCHAR(20) NOT NULL,           -- 角色：user/assistant/system
    Content NVARCHAR(MAX) NOT NULL,      -- 消息内容
    Tokens INT DEFAULT 0,                -- Token数量
    PluginCalls NVARCHAR(MAX),           -- 插件调用记录（JSON）
    CreatedTime DATETIME2 NOT NULL,
    
    FOREIGN KEY (ConversationId) REFERENCES AI_Conversations(Id),
    INDEX IX_AI_Messages_ConversationId (ConversationId)
);
```

#### 3. AI_Agents（代理配置表）
```sql
CREATE TABLE AI_Agents (
    Id VARCHAR(100) PRIMARY KEY,         -- 代理ID
    Name NVARCHAR(100) NOT NULL,         -- 代理名称
    Description NVARCHAR(500),           -- 描述
    SystemPrompt NVARCHAR(MAX),          -- 系统提示词
    ModelProvider VARCHAR(50),           -- 模型提供商：OpenAI/AzureOpenAI
    ModelId VARCHAR(100),                -- 模型ID
    Temperature DECIMAL(3,2) DEFAULT 0.7,-- 温度参数
    MaxTokens INT DEFAULT 2000,          -- 最大Token数
    Enabled BIT DEFAULT 1,               -- 是否启用
    CreatedBy BIGINT,                    -- 创建人
    CreatedTime DATETIME2 NOT NULL,
    UpdatedTime DATETIME2,
    
    INDEX IX_AI_Agents_Enabled (Enabled)
);
```

#### 4. AI_Plugins（插件配置表）
```sql
CREATE TABLE AI_Plugins (
    Id VARCHAR(100) PRIMARY KEY,         -- 插件ID
    Name NVARCHAR(100) NOT NULL,         -- 插件名称
    Description NVARCHAR(500),           -- 描述
    Type VARCHAR(50),                    -- 类型：Native/Prompt/OpenAPI
    AssemblyName VARCHAR(200),           -- 程序集名称（Native插件）
    ClassName VARCHAR(200),              -- 类名（Native插件）
    ConfigJson NVARCHAR(MAX),            -- 配置JSON
    Enabled BIT DEFAULT 1,               -- 是否启用
    CreatedTime DATETIME2 NOT NULL,
    
    INDEX IX_AI_Plugins_Enabled (Enabled)
);
```

#### 5. AI_AgentPlugins（代理-插件关联表）
```sql
CREATE TABLE AI_AgentPlugins (
    Id BIGINT PRIMARY KEY,
    AgentId VARCHAR(100) NOT NULL,       -- 代理ID
    PluginId VARCHAR(100) NOT NULL,      -- 插件ID
    CreatedTime DATETIME2 NOT NULL,
    
    UNIQUE INDEX UX_AgentPlugin (AgentId, PluginId),
    FOREIGN KEY (AgentId) REFERENCES AI_Agents(Id),
    FOREIGN KEY (PluginId) REFERENCES AI_Plugins(Id)
);
```

#### 6. AI_VectorCollections（向量集合表，可选）
```sql
CREATE TABLE AI_VectorCollections (
    Id VARCHAR(100) PRIMARY KEY,         -- 集合ID
    Name NVARCHAR(100) NOT NULL,         -- 集合名称
    Description NVARCHAR(500),           -- 描述
    Provider VARCHAR(50),                -- 向量数据库提供商
    ConfigJson NVARCHAR(MAX),            -- 配置JSON
    DocumentCount INT DEFAULT 0,         -- 文档数量
    CreatedTime DATETIME2 NOT NULL,
    
    UNIQUE INDEX UX_CollectionName (Name)
);
```

## 风险评估与应对

### 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| **API 密钥泄露** | 高 | 中 | 使用环境变量/密钥管理服务，不在代码中硬编码 |
| **Token 费用超支** | 中 | 中 | 实现配额管理、用量监控、自动告警 |
| **响应延迟过高** | 中 | 高 | 实现缓存机制、异步处理、超时控制 |
| **向量数据库性能瓶颈** | 中 | 低 | 选择合适的向量数据库、索引优化、分页查询 |
| **Semantic Kernel 版本升级兼容性** | 低 | 中 | 锁定版本号、定期评估升级、编写迁移指南 |

### 业务风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| **用户使用率低** | 高 | 中 | 提供丰富的示例、教程、模板，降低上手难度 |
| **合规性问题** | 高 | 低 | 实现内容审核、数据脱敏、符合 GDPR/网络安全法 |
| **AI 生成内容不准确** | 中 | 高 | 提供人工审核机制、置信度评分、引用来源 |

### 应对策略

1. **安全加固**
   - 实现 API 密钥轮换机制
   - 添加请求频率限制
   - 敏感信息自动脱敏
   - 内容审核过滤器

2. **成本控制**
   - 按用户/租户设置 Token 配额
   - 实现缓存机制减少重复调用
   - 提供成本估算和预警
   - 支持本地模型（Ollama）降低成本

3. **性能优化**
   - 异步处理和并行执行
   - 响应流式输出提升用户体验
   - 向量索引优化
   - 热点数据缓存

4. **质量保证**
   - 全面的单元测试和集成测试
   - 性能基准测试
   - 用户验收测试（UAT）
   - 持续监控和告警
